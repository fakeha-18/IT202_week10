# IT202 Week 10 Class Participation

## Student Search Application

This project uses PHP, MySQL, and sessions to search for a student by ID and display their information.

## Website
https://web.njit.edu/~fi53/week10/student_search.php

## GitHub
https://github.com/fakeha-18/IT202_week10

## PHP Files
- student_search.php — Searches for a student ID.
- student_info.php — Displays student information, courses, and grades using INNER JOIN.

## Features
- Student ID search form
- PHP sessions
- MySQL database connection
- INNER JOIN query
- Error alert for invalid student IDs
- HOME/BACK button
